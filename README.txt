Hungry Brunch Cafe & Restaurant website

Files:
- index.html: original page markup
- style.css: original inline CSS extracted without design changes
- script.js: original inline JavaScript extracted without behavior changes
- images/: image files extracted from the original HTML

To preview: open index.html in a browser.

GitHub Pages: upload index.html, style.css, script.js, and the entire images folder to the repository root. Do not upload only the ZIP file.

Note: Google Maps and WhatsApp links require an internet connection.
